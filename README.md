# Генератор документов кооператива

Статический сайт: заполняет шаблоны устава, протокола № 1 и пакета подключения к платформе. Браузер пользователя заполняет шаблоны .docx сам, данные формы (ФИО, паспорта, ИНН учредителей) не передаются на сервер и нигде не сохраняются.

Сайт: https://coopenomics.github.io/generate-documents/

## Устройство

```
apps/frontend/                 Next.js 14, статическая сборка (output: export)
  public/templates/            шаблоны .docx, поля в {фигурных скобках}
    new-cooperative/           устав и протокол № 1
    connection-package/        пакет подключения к платформе
  src/lib/generator.ts         подготовка данных и заполнение шаблонов (docxtemplater, pizzip)
packages/shared/               типы данных формы
.github/workflows/pages.yml    сборка и публикация на GitHub Pages при push в main
```

## Разработка

```bash
pnpm install
pnpm dev          # http://localhost:3001
pnpm build        # статический сайт в apps/frontend/out
```

Шаблоны Word для ручного заполнения (`public/samples`) собирает `scripts/make-samples.mjs` из тех же .docx при каждой сборке.

Кнопку «заполнить пример» включает переменная сборки `NEXT_PUBLIC_SHOW_TEST_BUTTON=true`.

## Обновление шаблонов

Замените файл в `apps/frontend/public/templates/<набор>/`. Имена полей в шаблоне должны совпадать с ключами из `src/lib/generator.ts`. Новый шаблон набора добавьте в список `TEMPLATE_SETS` того же файла.
